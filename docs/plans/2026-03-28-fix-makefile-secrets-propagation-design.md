# Design: Fix Makefile Secrets Command Failure Propagation

## 1. 現状の課題
`Makefile` の `link-secrets` ターゲットにおいて、`if` ブロック内の `cp` コマンドと `echo` コマンドがセミコロン（`;`）で連結されています。これにより、`cp` コマンドが失敗しても、続く `echo` コマンドが成功するとシェル全体の終了ステータスが `0`（成功）となってしまい、`make` がエラーを検知できず異常終了を見逃すリスクがあります。

## 2. 解決策
セミコロン（`;`）を `&&`（AND 演算子）に置き換えます。これにより、`cp` コマンドが失敗した時点でブロックの実行が中断され、非ゼロの終了ステータスが呼び出し元の `make` プロセスに伝播するようになります。

## 3. 影響範囲
- `Makefile`: `link-secrets` ターゲット内の `cp` 実行箇所。
- `_mk/*.mk`: 調査の結果、同様のパターンは見当たりませんでした。

## 4. 検証計画
### 4.1. 正常系
- `make link-secrets` を実行し、ファイルが正常にコピーされ、メッセージが表示されること。
- 終了ステータスが `0` であること。

### 4.2. 異常系
- 書き込み権限のないディレクトリを指定する、あるいはコピー元ファイルが存在しない状況を模擬し、`cp` を失敗させる。
- `make link-secrets` がエラーメッセージを表示し、非ゼロの終了ステータスで停止すること。
- 後続の `echo` コマンドが実行されないこと。
